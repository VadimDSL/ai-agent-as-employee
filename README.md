# AI Agent as Employee — Crowd Git

Публичный репозиторий для совместной разработки с модерацией через Pull Requests. Все изменения в `main` проходят через ревью владельца (CODEOWNERS).

Ключевые файлы:
- План развёртывания/модерации: `crowd-git/plan.md` [CANONICAL]
- Контекст/видение: `crowd-git/brief.md` [REF: crowd-git/brief.md]
- Правила вкладов: `CONTRIBUTING.md`
- Кодекс поведения: `CODE_OF_CONDUCT.md`
- CODEOWNERS: `.github/CODEOWNERS`
- PR Template: `.github/PULL_REQUEST_TEMPLATE.md`
- CI: `.github/workflows/validate.yml`

Структура (минимум):
```
crowd-git/
  plan.md
  brief.md
roles/
  project-manager/
    skills/
  office-manager/
    skills/
  marketer/
    skills/
  sales-manager/
    skills/
shared-skills/
```
