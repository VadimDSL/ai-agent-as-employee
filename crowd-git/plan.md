# План разворачивания публичного crowd-git репозитория с модерацией коммитов

[REF: crowd-git/brief.md]

Цель: создать публичный репозиторий ("эталонный git-репозиторий") для совместной работы комьюнити, где владелец подтверждает или отклоняет изменения через ревью PR, без прямых коммитов в `main`.

— Источник контекста: описание намерений и структуры в `brief.md` (подпапки по ролям и скиллам).
— Модель модерирования: все внешние изменения идут через Pull Request; слияние в `main` возможно только после подтверждения Code Owner.

См. корневой `README.md` для быстрых ссылок.
